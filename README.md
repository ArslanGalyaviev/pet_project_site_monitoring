# Site Monitoring Service

Асинхронный микросервис для мониторинга доступности сайтов с уведомлениями по email.

## Возможности

- **Асинхронная проверка** сайтов с настраиваемой периодичностью
- **Сохранение состояния** в SQLite базе данных (счетчик ошибок, статус алертов)
- **Защита от спама**: уведомление отправляется только после 5 последовательных ошибок
- **Email-уведомления** через SMTP (Яндекс.Почта)
- **Модульные тесты** с pytest

## Технологии

- Python 3.12+
- asyncio, httpx (асинхронные HTTP-запросы)
- SQLModel + aiosqlite (ORM и база данных)
- aiosmtplib (асинхронная отправка email)
- pytest + pytest-asyncio (тестирование)
